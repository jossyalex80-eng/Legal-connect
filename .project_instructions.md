# Legal Connect - AI-Powered Legal Marketplace

## Project Overview
Legal marketplace connecting clients with lawyers using AI-powered matching. Phase 1 MVP.

## Design
- **Colors**: Royal Blue (#1e3a8a primary), White, Gold/Amber (#d4a843 accent)
- **Style**: Modern, clean, premium, trustworthy
- **Fonts**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (mono)

## Architecture
- Route groups: `(public)` for public pages with Navbar/Footer, `auth` for login/register, `dashboard` for authenticated pages
- Database: PostgreSQL with Prisma ORM
- Auth: NextAuth v4 with Credentials + Google SSO (placeholder credentials)
- File uploads: S3 presigned URLs
- AI: Abacus AI LLM API for case-lawyer matching

## Key Pages
- Landing, About, Contact, Privacy, Terms (public)
- Login, Register with Client/Lawyer toggle (auth)
- Dashboard, Submit Case, My Cases, Case Detail, Case Matches, Profile (dashboard)
- Lawyer Search, Lawyer Profile (public)

## Database
- Users, LawyerProfiles, Cases, CaseRecommendations, ContactSubmissions
- 7 seed lawyers with various practice areas
- Test account seeded
